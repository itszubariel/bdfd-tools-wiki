Hex colors are codes that represent colors using hexadecimal values for red, green, and blue. Escaper

Here you can escape special characters to use in ur code.

Note

Escape characters are used to treat special symbols as plain text instead of triggering functions. This lets your bot return characters like ;, $, ], \ inside your message without breaking the script.

Character Escaper

Paste text to escape. Click Escape Code to process.

0 / 0 characters

Escaping Rules

Note

These characters are changed:

$ → %{DOL}%

] → \]

; → \;

\ → \\

Functions

Note

Use in BDFD functions like $sendMessage[], $async[], embeds, etc.

Example

$nomention
$sendMessage[[%{DOL}%Hello\\; this is pretty cool\\; right%{DOL}%\\]]
!example [$Hello; this is pretty cool; right$]

How to use?

Paste text → Escape Code → Copy Output → Paste in BDFD.
