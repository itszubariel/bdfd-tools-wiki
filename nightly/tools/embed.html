Functions

Note

Generated code uses standard BDFD embed functions.

Core:

  • $title[], $description[], $color[], $image[], $thumbnail[]
  • $author[], $footer[], $addTimestamp
  • $addField[], $addButton[], $addSelectMenuOption[]
  • $newModal[], $addTextInput[]
  • $sendEmbedMessage[]
  • $addContainer[], $addTextDisplay[], $addSeparator[], $addSection[]
  • $addThumbnail[], $addMediaGallery[], $addMediaGalleryItem[]
  • $addActionRow[], $addButtonCV2[], $addUserSelect[], $addRoleSelect[], $addMentionableSelect[]
